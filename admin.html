Secure administration

This is a static GitHub Pages website. A password placed in HTML/JavaScript would NOT be secure because visitors can inspect it.

  1. Keep the GitHub repository private if your GitHub plan/settings permit the workflow you choose, or understand that GitHub Pages source can be public.
  2. Protect the GitHub account with a unique strong password and 2FA.
  3. Only trusted people should have repository write access.
  4. Never put GitHub tokens/passwords into website files.

Update content

Replace the three files in assets/images to update the main photos. Commit the changes to GitHub and GitHub Pages will publish them.
