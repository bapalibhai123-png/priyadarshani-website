## Free GitHub Pages setup
1. Create a GitHub account.
2. Create a repository named `priyadarshani-website`.
3. Upload everything inside this folder.
4. GitHub → repository → Settings → Pages.
5. Choose **Deploy from a branch**, `main`, `/ (root)`, Save.
6. Open the GitHub Pages URL.

## Security
Do not create a fake JavaScript password. It is visible to visitors.
Your GitHub account is the actual administrator. Use a unique strong password + 2FA and do not share repository write access unnecessarily.
